# 聊天记录分享

## 需求与实现计划

- [x] 主站所有共用 `/chat/[id]` 的智能体支持选择用户消息和智能体回复、全选、取消和生成链接。
- [x] 分享前读取持久化消息编号；服务端验证登录、会话归属和完整选中集合，按原会话顺序保存不可变快照。切换会话时忽略旧请求的回调。
- [x] `/share/[token]` 无需登录，只展示选中消息、智能体名称、时间和展示用附件；不包含原对话标题、提示词、知识库原文、账号信息或后续对话。
- [x] 使用 256 位随机分享令牌。新增 `chat_shares` 表，首次使用幂等建表，同时维护前后端 Prisma schema。
- [x] 管理员用量汇总及明细分开显示来源、模型。请求上下文记录智能体编号和名称，历史无名称数据明确显示未记录。
- [x] 测试归属校验、空选/重复/外来消息、顺序、快照隔离、匿名读取、无效链接、HTML 转义、请求上下文隔离，并运行类型检查与构建。

起芽知识库在独立 SSO 子站；聊天分享同步实现在 `zxc9802/qyzsk` 的 `master` 基础分支中，子站使用自己的存储及分享链接。主站 SSO 登录协议不变。

## 部署

`chat_shares` 是新增表，首次创建分享或读取分享时创建；数据库账号需有建表权限，或部署前按 Prisma schema 创建该表。原会话删除或继续聊天不会改变已经分享的快照。

每次最多 200 条消息，快照最大 2 MB。当前分享无自动过期和撤销。生成图片及持久化预览沿用现有资源 URL，资源本身需保持可访问；原会话只保存临时 `blob:` 预览的上传附件仅分享文件名，不传输原文件或解析全文。
